# Security policy

AquaPulse controls real water supplies when used with hardware, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Instead, use GitHub's private reporting:
**Security → Advisories → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and the impact you expect. You will get a reply within 7 days.

## Supported versions

Until v1.0.0 is released, only the `main` branch receives security fixes.
